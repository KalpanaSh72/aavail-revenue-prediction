# Peer-review checklist

Only mark an item complete after verifying it.
- [ ] API tests pass.
- [ ] Model tests pass.
- [ ] Logging/monitoring tests pass.
- [ ] One command runs all tests.
- [ ] Runtime and prediction success are monitored.
- [ ] Tests do not overwrite production artifacts/logs.
- [ ] API supports one country and `ALL`.
- [ ] Data ingestion is reusable.
- [ ] Multiple models compared on chronological holdout.
- [ ] EDA visualizations reviewed.
- [ ] Docker image builds and runs.
- [ ] Model vs baseline plot included.

Still required: original course dataset, consistent persisted country encoder and inference pipeline, real-data EDA and baseline chart, and verified test/Docker runs.
